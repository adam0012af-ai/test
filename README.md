# DownloadHub

Android downloader + M3U/M3U8 parser and exporter.

## Features
- Direct HTTP/HTTPS file and video downloads.
- Public-page video extraction with TikTok clean-playback preference when exposed by the page.
- M3U/M3U8 import from URL or local file.
- Automatic export to `Channels.txt`, `Movies.txt`, and `Series.txt` under `Downloads/DownloadHub`.
- No DRM, login, or protection bypass.
